# ADR-0001: 仕様駆動開発 × エージェント開発を採用する
- Status: accepted (2026-11-21, ユーザー指示)
- Context: 複数エージェント（Claude Code / Codex / Muse）が同じ repo を触る。口頭と都度の指示だけでは仕様が散らかり、著者と検査役が混ざる
- Decision: 仕様（REQUIREMENTS.md）を正本とし、変更は 仕様→計画→タスク（完了条件つき）→実装→別エージェントのレビュー→仕様へ反映 の順で進める。完了は証拠つきでのみ受理する
- Consequences: 手順の固定費が増える代わりに、セッションを跨いでも状態が再現できる
