# ADR-0003: 帯の色は Google 標準パレットの原色のまま使う
- Status: accepted (2026-11-21, 実測とコード照合に基づく)
- Context: 「色の質感がチープ」という指摘を受けて実測したところ、帯の色値は BC とほぼ一致し、薄める処理も存在しなかった（REQUIREMENTS.md §7）
- Decision: パレット値（colorId の GoogleEventColors とカレンダー色）は変更しない。質感の差は描画の仕上げ（帯の高さ、余白、文字の大きさ・太さ）で詰める
- Consequences: 色に関する変更提案は、まず実測（ピクセルサンプリング）とコード照合を根拠にすること
